PdfKopi portable mode

While this file sits next to pdfkopi.exe, PdfKopi keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the PdfKopiData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move PdfKopi with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\PdfKopi and
%LOCALAPPDATA%\PdfKopi) instead. If PdfKopiData can't be written (for example on a read-only
drive), PdfKopi says so and uses the per-user folders instead.
